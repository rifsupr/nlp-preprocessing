# NLP Text Preprocessing

Tugas mata kuliah **Natural Language Processing (NLP)** — UNPAM.

## Deskripsi

Project ini berisi implementasi tahapan **text preprocessing** dalam NLP, meliputi:

- **Case Folding** — Mengubah teks menjadi huruf kecil
- **Tokenizing** — Memecah teks menjadi token/kata
- **Filtering (Stopword Removal)** — Menghapus kata-kata yang tidak bermakna
- **Stemming** — Mengubah kata ke bentuk dasarnya

## Teknologi

- Python 3
- NLTK / Sastrawi (Stemmer Bahasa Indonesia)

## Cara Menjalankan

```bash
# Install dependencies
pip install -r requirements.txt

# Jalankan program
python main.py
```
